## 🌐 How to Deploy for Free

### Option 1: GitHub Pages
1. Initialize a Git repository in this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   ```
2. Create a repository on GitHub (e.g., `portfolio` or `<your-username>.github.io`).
3. Link and push your code:
   ```bash
   git remote add origin https://github.com/<your-username>/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, go to **Settings > Pages > Branch: main > Save**. Your site is now live!

### Option 2: Vercel or Netlify
- Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
